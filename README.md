# Golden Palace — сайт банкетного зала (Тольятти)

Статический сайт: только HTML, CSS и один файл JS. Ни сборки, ни сервера не нужно.

## Как посмотреть

Двойной клик по **ОТКРЫТЬ САЙТ.command**. Откроется браузер, окно терминала не закрывать.

## Страницы

| Файл | Что на ней |
|---|---|
| `index.html` | Главная: анимированный первый экран, конструктор рассадки, поводы, афиша, меню, галерея, форма брони, вопросы, контакты |
| `zal.html` | Зал: что есть внутри, четыре формата рассадки |
| `svadba.html` | Свадьба: ход дня, что берёт на себя зал, свадебные вопросы |
| `menu.html` | Банкетное меню по разделам |
| `afisha.html` | Афиши событий |
| `galereya.html` | Фотографии по разделам |
| `kontakty.html` | Адрес, карта, как добраться |

## Как вставить фотографии

Положить файл в папку `фото` с именем из **ФОТО.md** — плашка заменится картинкой сама,
вёрстку править не надо. Список всех имён и что на каждом кадре — в ФОТО.md.

## Форма брони

Backend не нужен: форма собирает сообщение и открывает WhatsApp зала
(+7 927 268-48-88) с готовым текстом. Номер задан один раз — в начале `assets/app.js`,
константа `PHONE`.

## Если правите стили или скрипт

В конце `href="assets/style.css?v=1"` и `src="assets/app.js?v=1"` стоит номер версии.
После правок поднимите его на всех страницах, иначе у людей останется старая версия из кэша.
